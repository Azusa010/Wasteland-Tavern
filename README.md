# 废土酒馆 · Wasteland Tavern

> 核战之后的荒原上，一家铁皮防空洞酒馆，是所有人最后的落脚点。

《废土酒馆》是一款融合了**叙事经营**与**卡牌 Roguelike**的昼夜双循环游戏。白天，你是一名酒馆老板，用调酒和对话招待拥有跨天记忆的 AI 废土客；夜晚，你深入辐射废墟，在牌局中搜集食材与物资，守住这家酒馆，也守住荒原上残存的人情。

## 游戏玩法

### ☀️ 白昼 · 酒馆经营

- **调酒招待**：使用 6 种废土原料（辐射水、变异土豆原浆、铁锈烘麦芽、幽光菌菇露、荒原安神草、核冬冰薄荷）自由搭配，调出招牌酒或私酿，依据客人的口味偏好影响其状态。
- **AI 驱动对话**：每位客人由大语言模型实时驱动，拥有独立人设、说话风格、隐藏目的与**跨天记忆**。你的每句话、每杯酒都会被记住，并在之后的来访中产生影响。
- **量化状态博弈**：信任、醉意、张力、瓶盖欠账等数值随互动实时变化，直接影响客人是掏心掏肺、借酒闹事，还是拔枪相向。
- **传闻与委托**：散布谣言、承接废墟委托、邀请同伴，为夜晚的探险铺路。

### 🌙 黑夜 · 废墟探险（卡牌 Roguelike）

- **城市选址**：在废弃商场、炮击诊所、废铁船坞、极寒反应堆等地点间抉择，每处风险与产出各不相同。
- **剖面探索**：进入建筑多层剖面，潜行绕后可发动先手偷袭，触发遭遇战、拾荒、工作台与幸存者交涉。
- **卡牌战斗**：由攻击、防御、拾荒、连击等卡牌构筑牌库，配合能量与意图系统，与变异鼠、辐射猎犬、掠夺者、哨兵机器人乃至霜爪 Boss 交锋。
- **成长构筑**：分配 RPG 属性点、选择天赋 Perk、升级卡牌，逐渐打造属于你的牌组流派；黎明满载战利品归店，开启新的一天。

### 🎬 特色

- **昼夜双循环**：叙事经营 × 卡牌肉鸽，白天的人际积累直接影响夜晚的生存几率。
- **四位核心常客**：阿灰（拾荒客）、伊恩·K-7（逃亡合成人）、老铁锤·巴克（金盆洗手的掠夺者）、老算盘·莫里（游商老头），每位都有专属人设、秘密与剧情线。
- **多结局与无尽模式**：在限定天数内经营酒馆，走向属于你的结局；通关后可开启无尽模式继续经营。
- **多槽位存档**：自动存档 + 三个手动归档位，随时回到任意一天。
- **沉浸式视听**：第一人称酒馆舞台、手绘立绘与场景贴图、电台 BGM、音效与角色语音朗读（TTS）。

## 技术实现

- **前端**：React 19 + TypeScript + Vite 8 + Tailwind CSS 4 + Motion
- **后端**：Express 服务，负责调用大语言模型 API（支持 Gemini / ModelScope / OpenCode 等通道）
- **AI**：NPC 对话、开场白、递酒品鉴均由 LLM 实时生成，并通过规则引擎校验后写入游戏状态

## 本地运行

**环境要求**：Node.js

1. 安装依赖：
   ```bash
   npm install
   ```
2. 在 [.env.local](.env.local) 中配置相应通道的 API Key（如 `GEMINI_API_KEY`）。
3. 启动游戏：
   ```bash
   npm run dev
   ```
4. 浏览器打开终端中显示的本地地址即可开始游戏。

> 你也可以在游戏的「设置」面板中切换 LLM 服务商、模型与接口地址。

## 部署到魔搭创空间

项目已包含 Docker 部署三件套:`Dockerfile`、`ms_deploy.json`、`.dockerignore`。

1. 创建 **Docker** 类型的创空间(需完成阿里云账号绑定与实名认证)。
2. 将本仓库推送到创空间 Git 仓库(分支须为 `master`,不支持强推):
   ```bash
   git remote add modelscope oauth2:<你的访问令牌>@modelscope.cn/studios/<用户名>/<创空间名>.git
   git push modelscope master
   ```
3. 在创空间「设置 → 环境变量/密钥」中填入 `MODELSCOPE_API_KEY`(或平台内置 `MODELSCOPE_SDK_TOKEN`),建议同时设置 `LLM_PROVIDER=modelscope`。
4. 平台会自动构建并启动容器,服务将监听创空间要求的 `0.0.0.0:7860`。

> 注意:创空间要求服务必须监听 **7860** 端口(由 `Dockerfile` 中的 `PORT=7860` 保证);`npm start` 生产模式需 Node 原生运行 `server.ts`,已通过带 `.ts` 后缀的导入路径修复扩展名解析问题。
